About this dashboard

Dataset

  • 5,653 transaction records across 21 columns
  • Coverage: January 2021 – August 2023 (August is partial)
  • 4 regions, 12 states, 5 product categories, 15 products, 3 sales channels
  • No missing values or duplicate rows detected

Prediction approach

  • Revenue trend forecast: ordinary least squares trend line fitted on monthly revenue, adjusted by a monthly seasonal index, extended forward by the chosen horizon
  • Transaction revenue estimator: multiple linear regression (normal equations) on units sold, price, marketing spend, discount, shipping cost and one-hot encoded region / category / channel
  • Both models are trained live, in JavaScript, from the data currently loaded — nothing is precomputed or hardcoded

Limitations

  • All accuracy, R², RMSE and MAE figures are calculated from the loaded data at run time — none are invented
  • A linear model cannot capture non-linear seasonality shocks or one-off events; treat forecasts as a trend baseline, not a guarantee
  • August 2023 has only 73 of the usual ~180 monthly records and is excluded from trend fitting as a partial month
  • Uploading a replacement file works best when it keeps the same column names as the original dataset
This dashboard runs entirely client-side — there is no server, database or Python backend. It is a single self-contained HTML file and can be hosted as-is on GitHub Pages.
